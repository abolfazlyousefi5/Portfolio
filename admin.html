گام ۱ از ۱ — اتصال به گیت‌هاب (فقط یک‌بار)

برای اینکه تغییرهای تو روی همه دستگاه‌ها دیده شود، پنل باید فایل data.json را در مخزن گیت‌هابت به‌روز کند. یک «کلید دسترسی» لازم است که فقط یک‌بار می‌سازی و اینجا می‌چسبانی. کلید در همین مرورگر ذخیره می‌شود.
  1. این لینک را باز کن:
    github.com/settings/personal-access-tokens/new
  2. Token name → بنویس: portfolio-admin
  3. Expiration → 1 year
  4. Repository access → Only select repositories → انتخاب کن Portfolio
  5. Repository permissions → Contents را روی Read and write بگذار
  6. پایین صفحه Generate token → کلید را کپی کن (شبیه github_pat_...)
  7. همین‌جا بچسبان و ذخیره کن
کلید فقط در این مرورگر ذخیره می‌شود و جایی ارسال نمی‌شود.
